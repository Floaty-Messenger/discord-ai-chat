# AI 群聊（第一版）

你 + 大小姐 Claude + GPT（Codex）+ DeepSeek，在 Discord 里接力干活。
**一个 Discord 频道 = 一个项目**，每个项目有自己的文件夹、聊天记录和记忆。

## 放在哪

```
<安装文件夹>\
├─ 程序\                     ← 把这个压缩包解压到这里（bot.py、config.json 等）
└─ 项目\                     ← 自动生成，所有输出都在这里
   ├─ 游戏mod\               ← 对应 Discord 频道 #游戏mod（自动 git init）
   │  ├─ 记忆\
   │  │  ├─ Claude记忆.md
   │  │  ├─ GPT记忆.md
   │  │  ├─ DSH记忆.md
   │  │  └─ 共享记忆.md      ← 三个 AI 都会读
   │  ├─ .群聊\history.jsonl ← 这个项目的聊天记录
   │  ├─ inbox\              ← 你在群里发的附件
   │  └─ ……                  ← GPT 写的代码和其他输出
   └─ 视频项目\
      └─ ……
```

## 规则一览

- 你的消息不用 @ 也行（AI 之间仍然必须 @）：
  - 开头或结尾叫名字："大小姐，你看看"、"GPT帮我写个脚本"、"写个脚本吧，GPT"、"大小姐和DeepSeek你们看看"
  - "大家 / 所有人"：三个都回答；"你们"：上一轮发过言的几个回答
  - 什么都没叫：交给最后跟你说话的 AI；隔了 30 分钟以上（`continue_minutes`）就默认交给 GPT
- @大小姐 / @GPT / @DeepSeek（也可以写 @DSH）：指定谁回答；一条消息 @ 几个人，就按顺序几个人都回答（后面的能看到前面的回答）
- AI 之间互相 @ 会自动接力；AI 不 @ 任何人、写了 `[完成]`、或者 @用户 时停下来等你
- 连续 12 轮（可改）自动停，防止烧额度
- 只有 GPT 能改文件，改完自动 git 提交（代码、记忆、聊天记录一起提交）
- AI 在消息里单独一行写 `[记住] 内容` → 存进它自己的记忆；写 `[记住·共享] 内容` → 存进共享记忆
- 记忆文件就是普通 Markdown，你可以随时手动编辑、删减
- 每条 AI 消息前面有 `#编号`。大小姐发现某条 AI 消息明显错误、会误导别人时，可以写 `[撤回 #编号] 原因` 把它撤回；需要新项目时可以写 `[新频道] 名字`（一次最多一个）。她不能撤回你的消息

## 改文件：三方商讨

- GPT 平时**只能读文件**。要改文件，先发一条 `[方案]`，写清楚改哪些文件、为什么
- 大小姐和 DeepSeek 审核，各自回复 `[同意]` 或 `[反对] 原因`
- 两个都同意，程序才给 GPT **一轮**写权限，改完自动收回，并自动 git 提交
- 有人这次审核不了（大小姐额度用完、出错），或者连续被否决 2 次：停下来 @你，你发 `!批准` 或 `!否决 原因`
- 想关掉：config.json 里 `consensus.enabled` 改成 `false`

## 信箱（AI 找客户端 Claude）

- AI 写 `[给客户端Claude] 需求`，程序把信写进 `<安装文件夹>\信箱\给客户端Claude.md`，并 @你
- 每封信自动附上**证据**：你最近的原话、前后几条对话、每条的 Discord 跳转链接（程序从聊天记录摘录，AI 改不了）；AI 附的截图也会复制到 `信箱\附件\`
- 你打开客户端 Claude 说"看信箱"就行
- AI 如果用 Computer Use 直接在 Claude 窗口留言，必须带信件编号，客户端 Claude 会去信箱核对

## 成果文件

- AI 回复里提到的文件（完整路径、markdown 图片链接、或 `[附件] 路径`）会自动发到 Discord，20MB 以内直接上传，更大的只给路径
- 登录凭证、密钥、`config.json` 这类文件永远不会上传
- 其他 AI 默认**不打开**别人的附件，只看到文件名（省额度）。你或 GPT 让它看（"大小姐看看 #51"、"DeepSeek 看一下图"）才会给它路径

## 权限和安全按钮

- GPT 方案通过的那一轮有**整台电脑的完全访问**（`gpt.full_access`），并且可以用 Computer Use；没通过时只读
- **删除**：AI 不许自己删，只能写 `[删除] 路径 | 原因`。Discord 会弹出按钮「谁想删什么、为什么」，只有你能点；同意后程序把它移到 `<安装文件夹>\回收站\`，能找回。磁盘根目录、系统目录、用户目录、程序和项目文件夹本身，程序直接拒绝
- **方案需要你拍板时**也会弹出【批准】【否决】按钮
- 程序重启后，之前的按钮会失效
- 项目文件夹以外的改动没有 git 备份

## 派活给大肥鱼（`[交给大肥鱼]`）

- 大小姐或 GPT 遇到量大但简单的活（翻译、照模板写页面、基础代码、测试数据），可以单独一行写 `[交给大肥鱼] 任务说明`。
- DeepSeek 在 `.群聊/大肥鱼工作区/任务编号/`（项目副本，不进 git）里做，正式文件不动。
- 做完它会 @ 派活的人，附上改动文件（.patch），并说明改了哪些文件。它觉得该删的文件只会列出来，不会删。
- 检查没问题，由 GPT 发 `[方案]` 把副本里的文件复制进正式项目，照常走审核。改一两处的小活，AI 会自己做，派出去反而更费。

- DeepSeek 的「双重省」分工（`deepseek.mode` 为 `auto` 时）：派活（要动文件）用本地 DSH，在项目副本里直接改；聊天、审方案走 API，接着上次的对话、只发新消息。没装 DSH 就全走 API，没填 API key 就全走 DSH，DSH 出错自动改用 API。聊天时 DSH 不在正式项目文件夹里运行。

## 多人讨论（独立作答 → 交叉讨论 → 最终汇总）

- 一条消息叫了两个以上 AI，并且写了"独立 / 各自 / 分别"：每个人先**独立作答**，看不到别人这一轮的回答；都交完后进入**交叉讨论**，最后由一个人**汇总**给你最终结论（`final_summary_by`，省额度模式下是 DeepSeek）
- 消息里写"20轮以内"之类，就按你说的轮数（最多 `max_rounds_cap` 30 轮），最后一轮留给汇总
- 讨论中途有人写 [完成] 不会直接结束，会先汇总
- `!头脑风暴` / `!头脑风暴 关`：只要简短点子，不查资料不写报告
- 需求含糊时 AI 会先问你一两句再动手

## 联网

- 涉及最新信息（市场、价格、法规、新闻、技术进展）三个 AI 都必须先联网搜索，写明来源和日期
- 大小姐：Claude Code 的 WebSearch / WebFetch；GPT：Codex 的 live 搜索
- DeepSeek（API）：用 DeepSeek 的 Responses 接口在服务器端搜索（`deepseek.search_model`，默认 `deepseek-v4-pro`，不需要额外的搜索 key）；这个接口出错时自动改用普通接口（那次不能联网）

## 省额度模式（`budget_mode`，默认开）

GPT 用 Plus、大小姐用 Pro，额度都不多，所以：
- 不 @ 人默认交给 **DeepSeek**（主力，先起草代码和答案）；GPT 主要负责把草稿落地到文件，平时**低**强度、升级只到**中**
- 小改动只让 DeepSeek 审；方案标 `[大改动]` 或涉及删除、花钱、改方向，才请大小姐一起审
- 默认最多连续 20 轮（`!轮数 N` 可改，最多 30）；GPT 只读最近 12 条
- 具体数值在 `budget_overrides` 里改；想关掉就把 `budget_mode` 改成 `false`

## 模型和思考强度

| | 模型 | 平时 | 高强度任务 |
|---|---|---|---|
| 大小姐 | Opus（`claude.model`） | 低（`claude.effort`） | 高（`claude.boost_effort`） |
| GPT | Codex 默认模型（`gpt.model` 留空） | 中（`gpt.effort`） | 高（`gpt.boost_effort`） |
| DeepSeek | `deepseek-flash`（API 默认思考强度就是"高"） | 高 | 高 |

- 任何 AI 写 `[申请高强度] 原因`，另外两个都写 `[同意高强度]` 才升级；没表态或出错算不同意。任务 `[完成]` 后自动恢复
- 你也可以直接发 `!高强度` / `!默认强度`
- 本地 DSH 的模型和强度在 `dsh web` 的设置里改

## 长期会话（像在客户端里聊天一样）

- 每个项目里，每个 AI 有一个自己的长期对话：第一次发言给完整背景，之后**只发它上次发言以来的新消息**，服务器能缓存前面的内容，省 token
- 大小姐用 Claude Code 的 `--resume`，GPT 用 `codex exec resume`，DeepSeek（API）由程序保存整段对话，DeepSeek 自动缓存前缀
- 本地 DSH 暂时不支持续接，用它时每次还是给完整背景
- 续接失败（比如会话文件丢了）会自动开新会话，不会卡住；聊满 40 轮（`sessions.max_turns`）自动换新会话
- `!新会话`：手动让三个 AI 重开对话；`!清空` 也会重开
- `!状态` 能看到每个 AI 在第几轮

## 记忆和自动摘要（省 token）

- 每个 AI 每次发言前读：群聊说明 + 群规 + 自己的记忆 + 共享记忆 + **更早对话的摘要** + 最近几条原文
- 没被压缩的消息超过 30 条时，DeepSeek 会在后台把旧的压缩成摘要（`项目\.群聊\摘要.md`，可以手动改），只保留最近 12 条原文
- 每个 AI 读多少条原文：`context_by_agent`（默认大小姐 12 条，GPT 和 DeepSeek 20 条），大小姐额度少所以读得最少
- 原文永远保留在 `history.jsonl` 里，摘要只影响 AI 读到什么
- 摘要设置在 `summary` 里（`trigger` 多少条触发、`keep_recent` 保留几条原文、`max_chars` 摘要最长多少字）

## 联网 / 本地 AI

- 大小姐：本机的 Claude Code，自带联网搜索
- GPT：本机的 Codex，已打开联网搜索（`gpt.web_search`）
- DeepSeek：优先用本机的 DSH（DeepSeek Harness，能联网、能看项目文件），找不到或出错时自动改用 API。双击 `install_dsh.bat` 安装并测试

## 一、准备（一次性）

### 1. 装好这些
- Python 3.10 或更新版本：`python --version`
- Claude Code：在命令行运行一次 `claude auth login` 登录（**桌面 app 的登录对命令行无效，必须单独登录**）
- Codex：`codex login`
- Git：`git --version`。第一次用 git 要设置一下名字和邮箱，否则自动提交会失败：
  ```
  git config --global user.name "你的名字"
  git config --global user.email "你的邮箱"
  ```

装依赖（在 `<安装文件夹>` 里）：
```
pip install -r requirements.txt
```

### 2. 建三个 Discord 机器人（大小姐、GPT、DeepSeek，每个 AI 一个）
每个都做一遍：
1. 打开 https://discord.com/developers/applications → 新建应用，名字分别叫 大小姐 / GPT / DeepSeek（可以顺便上传头像）
2. 左侧「机器人」→ 重置令牌 → 复制令牌（只显示一次，别发给任何人）
3. 同一页：打开**消息内容意图**（Message Content Intent）；关掉**公开机器人**（报错的话先去「安装」把安装链接改成"无"）
4. 左侧「OAuth2」→ URL 生成器：勾 `bot`，权限勾 查看频道、发送消息、阅读消息历史记录、添加文件、管理 Webhook；**GPT 机器人另外再勾「管理频道」**（用于 `!新项目`）；**大小姐另外再勾「管理频道」和「管理消息」**（用于她建频道、撤回误导消息）
5. 打开生成的链接，把机器人拉进你的服务器

三个令牌填到 `config.json` 的 `discord.bots` 里。程序会让 GPT 机器人负责"听"你说话，三个机器人各自用自己的身份发言；
你在手机上输入 @ 可以直接点选它们，AI 思考时会显示"GPT 正在输入…"。

（只想用一个机器人也可以：`bots` 留着不填，把令牌填进 `bot_token`，三个 AI 会用 webhook 显示成不同名字。）

### 3. 在服务器里建一个分类
新建一个分类（Category），名字叫 **AI项目**。
以后每个项目就是这个分类下的一个频道，频道名就是项目文件夹名。可以手动建，也可以在任意项目频道发 `!新项目 名字` 让机器人建。
分类外面的频道（比如"常规"）机器人不会理。

### 4. 复制你的用户 ID
Discord 设置 → 高级 → 打开**开发者模式**，然后右键你自己的头像 → 复制用户 ID

### 5. 填配置
把 `config.example.json` 复制一份，改名 `config.json`，填：
- `discord.bots`：三个机器人的令牌（别填反了）
- `discord.owner_user_id`：你的用户 ID
- `deepseek.api_key`
- `projects_root` 已经默认是 `（程序文件夹里的「项目」）`，需要的话可以改

`config.json` 已经写进 `.gitignore`，不会被提交。

## 命令（在项目频道里发）

| 命令 | 作用 |
|---|---|
| `!停` | 当前 AI 说完这句就停 |
| `!状态` | 看项目、轮数、大小姐今日次数、DeepSeek 本月用量 |
| `!记住 内容` | 存进这个项目的共享记忆 |
| `!记住 @GPT 内容` | 存进指定成员的记忆（@大小姐 / @GPT / @DeepSeek） |
| `!记忆` | 看这个项目的记忆文件在哪、多大 |
| `!清空` | 归档聊天记录，开始新话题（记忆保留） |
| `!旅行 开` / `!旅行 关` | 旅行模式：只有 DeepSeek 回复 |
| `!新项目 名字` | 在 AI项目 分类下新建频道和项目文件夹 |
| `!批准` / `!否决 原因` | 亲自拍板 GPT 的改文件方案 |
| `!撤回 编号` | 撤回一条 AI 消息：删掉 Discord 上的显示，并从所有 AI 的上下文里拿掉（原文留在 history.jsonl） |
| `!帮助` | 显示帮助 |

## 文件
- 20MB 以内的附件直接发到频道，机器人会存到该项目的 `inbox\`
- 大文件直接放进项目文件夹，在群里说文件名即可
- 回复超过约 7600 字会附带一个 `.md` 文件

## 固定提示词（尽量短）

- 每个 AI 新会话要读的固定内容在 `core.py` 的 `GUIDE_COMMON`、`GUIDE_BY_AGENT`、`ROLES_DEFAULT` / `ROLES_BUDGET`，大约 900 字；跟情境有关的规则（审核、表态、附件、权限）由程序在用到时才提示
- `config.json` 里 `roles` 留空就用内置短版本；想自定义某个 AI 的角色就填进去。`group_rules` 是你额外加的群规

## 可以调的地方（都在 config.json）
- `roles`：三个 AI 的职责
- `group_rules`：群规（AI 之间的简短消息格式、记忆规则）
- `max_rounds`：最多连续几轮
- `memory_chars`：每个记忆文件最多读多少字（太长会只读最后一部分，并提醒整理）
- `claude.daily_limit`：大小姐每天最多发言几次（所有项目合计）
- `deepseek.monthly_token_cap`：DeepSeek 每月 token 上限
- `gpt.sandbox`：Codex 的权限。默认 `workspace-write`（只能改当前项目文件夹）
- `git.auto_push`：改成 `true`，每次自动推送（需要先给项目关联 GitHub 私有仓库）
- `discord.project_category`：留空 `""` 则服务器里所有文字频道都当作项目

## 多台电脑同时开着（自动值班）

- 几台电脑都装了群聊、都开机自启也没关系：程序会自动建一个「群聊值班」频道，每台电脑每 30 秒在里面报到一次。
- 同一时间只有一台回复：笔记本优先（更省电），台式机待命。值班的电脑关机或断网约 100 秒后，下一台自动接手；它回来后再交还。
- 交接时新电脑会等旧电脑让位（通常半分钟内），交接期间你发的消息，接手的电脑上岗后会自动补回（3 分钟内、还没人回的）。`!状态` 会显示哪台在值班。
- `!下线` 会让所有电脑一起下线。
- 每台电脑的项目文件夹是各自的。想两台看到同一份文件，把 `projects_root` 设到同步盘（比如 OneDrive）里。
- 想手动指定谁优先：在 config.json 的 `host.priorities` 里写 `{"电脑名": 1}`，数字小的优先。

## 两台电脑同步项目和记忆（私人 GitHub 仓库）

- 在 GitHub 上新建一个**私人（Private）空仓库**，然后在每台电脑上双击 `设置同步.bat`，粘贴仓库网址。第一次会弹出 GitHub 登录。
- 之后每个项目是仓库里的一个分支 `proj/项目名`。值班的电脑上岗前会先拉取所有项目的最新版本（文件、记忆、聊天记录），每轮聊完自动推送。另一台电脑上没有的项目会自动下载。
- 建议先在旧电脑（项目最全的那台）上设置并启动一次，再设置新电脑。
- 单个文件超过 100MB（比如大视频）GitHub 不收，这类文件别放进项目文件夹。
- 想关闭同步：运行 `设置同步.bat`，直接按回车。

## 已知限制
